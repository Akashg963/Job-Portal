# Job Portal

A modern and responsive **Job Portal Web Application** built with **React.js**, **Vite**, **Tailwind CSS**, **Supabase**, and **Clerk Authentication**. The platform enables users to search for jobs, view job details, and securely authenticate using Clerk.

---

## 🚀 Features

- 🔐 Secure user authentication with Clerk
- 💼 Browse and search job listings
- 🔎 Filter jobs by category, location, and keywords
- 📄 View detailed job descriptions
- ⚡ Fast and responsive UI built with Vite
- 🎨 Modern interface using Tailwind CSS
- ☁️ Backend powered by Supabase
- 📱 Fully responsive across desktop, tablet, and mobile devices

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/job-portal.git
```

### 2. Navigate to the project

```bash
cd job-portal
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root.

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_PROJECT_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
VITE_CLERK_PUBLISHABLE_KEY=YOUR_CLERK_PUBLISHABLE_KEY
```

---

## ▶️ Run the Project

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
